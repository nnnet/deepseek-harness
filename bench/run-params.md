# Параметры и метрики прогонов — bench/qwen3.8-27b

Свод конфигурации и агрегированных метрик по всем рычагам плана
`.claude/plans/2026-08-27T20-36__dsh-local-qwen38-optimization.md`. Дополняет,
не дублирует: `bench/ledger.md` хранит сырые строки по каждому прогону (одна
строка = один реальный прогон эталонной задачи, `bench/task.md`), этот файл —
параметры LM Studio/dsh, которых в колонках ledger нет, и агрегаты по рычагу.
Разбор причин и решения по каждому рычагу — `bench/FINDINGS.md`.

Все числа — из реальных прогонов `dsh --profile bench` против живой LM Studio,
не из статики/оценки.

## Принятые/отклонённые рычаги (сводка решений)

- **C1 `local-fast`** — принят. Компакция обнулилась (2.33→0.00), `wall` упал на 37%.
- **C6 `persona`** — принят. `tool_err` упал на 75% (0.80→0.20) — целевой эффект; `wall` смешанно (медиана −21%, среднее +16% из-за одного выброса).
- **C2 `budget-512`** — отклонён. Хуже `1024` на всех пяти метриках; `256` не тестировали (однонаправленный сигнал, дальнейшее снижение не проверялось отдельным реальным прогоном).
- **C5 `local-seed`** — отклонён. `ouroboros_auto` не вызван ни разу за 5 прогонов (проверено по session-логам) — только стоимость (+15 847 токенов пола), `wall` ×2.66, `gate` 5/5→3/5.
- **C3 (компакция)** — не рычаг с отдельными прогонами: приёмка уже удовлетворена как побочный эффект C1, порог не трогали.
